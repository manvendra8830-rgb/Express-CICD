# Express CI/CD Application

## Project Overview

This project demonstrates a professional CI/CD workflow for an Express.js frontend application using Jenkins, GitHub, automated testing, and AWS EC2.

The Express application provides a web-based To-Do interface and communicates with the Flask backend through an API endpoint.

## Technology Stack

- Node.js
- Express.js
- JavaScript
- Node.js Test Runner
- Jenkins
- GitHub
- AWS EC2
- Linux
- Systemd
- GitHub Webhook
